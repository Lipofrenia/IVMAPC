# IVMAPC — Настройка проекта

## Требования
- Python 3.10+
- PostgreSQL 14+

## 1. Создание базы данных

Откройте `psql` (или pgAdmin) и выполните:

```sql
CREATE DATABASE ivmapc;
```

> База данных будет использовать пользователя `postgres` с паролем `1127456`.
> Если нужно изменить — отредактируйте файл `.env`.

## 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 3. Применение миграций

```bash
python manage.py migrate
```

> Django автоматически создаст все таблицы в базе данных.

## 4. Создание суперпользователя (администратора)

```bash
python manage.py createsuperuser
```

Укажите имя, email и пароль для доступа к админ-панели.

## 5. Загрузка начальных данных

```bash
python manage.py load_initial_data
```

Эта команда создаст:
- 6 категорий (Игровые компьютеры, Клавиатуры, Мониторы и др.)
- 9 товаров с фотографиями
- 5 слайдов для главной страницы
- Характеристики для CORE X1

## 6. Запуск сервера

```bash
python manage.py runserver
```

Сайт будет доступен по адресу: http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

## 7. Чат службы поддержки (WebSocket, Node.js)

Чат работает на отдельном WebSocket-сервере (Node.js 18+, порт **8080**).
Django отдаёт страницу чата, а сообщения идут напрямую между браузером и Node.js.

```bash
cd chat-server
npm install      # один раз — установит библиотеку ws
npm start        # запустит ws://localhost:8080
```

Затем во втором терминале запустите Django (`python manage.py runserver`) и откройте
http://127.0.0.1:8000/support/ (пункт меню «Поддержка»).
Для проверки откройте страницу в двух вкладках/браузерах под разными именами.

Файлы чата:
- `chat-server/server.js` — WebSocket-сервер (вход/выход, рассылка сообщений, «печатает…»)
- `templates/support.html` — разметка страницы чата
- `static/css/support.css` — стили чата
- `static/js/support-chat.js` — клиент WebSocket в браузере
- `shop/views.py` → `support_chat`, маршрут `support/` в `shop/urls.py`

> Адрес сервера можно изменить переменной `CHAT_WS_URL` в `.env`
> (по умолчанию `ws://<хост сайта>:8080`).

## Структура проекта

```
IVMAPC/
├── manage.py              # Утилита Django
├── .env                   # Настройки БД (НЕ коммитить!)
├── requirements.txt       # Зависимости Python
├── ivmapc/                # Конфигурация проекта
│   ├── settings.py
│   ├── urls.py
│   ├── wsgi.py
│   └── asgi.py
├── shop/                  # Основное приложение
│   ├── models.py          # Модели БД
│   ├── admin.py           # Настройка админки
│   ├── views.py           # Представления
│   ├── urls.py            # Маршруты
│   └── context_processors.py
├── templates/             # HTML-шаблоны
├── static/                # CSS, JS, шрифты, иконки
└── media/                 # Загружаемый контент (фото)
```

## Управление через админ-панель

### Товары
- Добавление/редактирование/удаление товаров
- Загрузка нескольких фотографий
- Настройка характеристик (быстрые + полные)
- Отметка «На главной» для показа на главной странице

### Слайдер
- Добавление/удаление слайдов
- Загрузка изображений
- Включение/выключение слайдов
- Порядок отображения

### Категории
- Управление категориями товаров
- Настройка тегов и подзаголовков

### Заказы
- Просмотр всех заказов
- Изменение статуса (Новый → В обработке → Доставлен)
