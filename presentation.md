## 1. Слайд: Введение
**Название проекта:** Интернет-магазин компьютерной техники «IVMAPC».  
**Автор:** *[Ваши Имя и Фамилия]*  
**Цель проекта:** Разработать современный, масштабируемых и удобный интернет-магазин для продажи компьютеров и периферии. Важной целью было создать не только красивый интерфейс для покупателей, но и мощную административную панель для полного управления контентом и заказами без необходимости вмешиваться в код.

## 2. Слайд: Для кого это и что умеет
**Целевая аудитория:** 
Геймеры, IT-специалисты, студенты и все пользователи, которым нужна качественная компьютерная техника, готовые сборки или периферия, с удобным процессом выбора и покупки.

**Функциональные требования (что было реализовано):**
- Интерактивный каталог с возможностью сортировки (по цене, новизне) и фильтрации по стоимости.
- Детальные карточки товаров с динамической фотогалереей и структурированными характеристиками.
- Корзина покупок, которая работает как для авторизованных пользователей, так и для гостей сайта.
- Личный кабинет с возможностью редактирования профиля (фото, телефон) и историей оформленных заказов.
- Онлайн-чат службы поддержки в реальном времени на базе протокола WebSocket (Node.js).
- Защищенная админ-панель для менеджера (добавление товаров, изменение остатков на складе, управление баннерами и статусами заказов).

## 3. Слайд: Технологический стек
Для реализации проекта я выбрал связку надежных и современных технологий.

**Backend (Серверная часть):**
- **Python 3** и фреймворк **Django**. Выбор пал на Django из-за его безопасности (защита от SQL-инъекций "из коробки"), встроенной админ-панели и архитектуры MTV.
- **Node.js (WebSocket / `ws`)** — отдельный сервер реального времени на порту 8080 для чата службы поддержки.

**База данных:**
- **PostgreSQL**. Надежная реляционная база данных для безопасного хранения чеков, пользователей и связей между товарами.

**Frontend (Клиентская часть):**
- Ванильные **HTML5 / CSS3 / JavaScript** для полного контроля над уникальным темным дизайном без перегрузки сайта тяжелыми UI-библиотеками.
- **Swiper.js** — для красивых и плавных слайдеров на главной странице.

## 4. Слайд: С какими трудностями столкнулся и как решил
В процессе разработки возникло несколько сложных архитектурных задач:

**Трудность 1: Работа корзины для гостей.**
Обычно корзина привязывается к аккаунту в базе данных. Но заставлять пользователя регистрироваться *до* добавления товара в корзину — это плохой UX.
* **Решение:** Я реализовал механизм привязки товаров в таблице БД к `session_key` (сессии браузера). Если пользователь гость — его товары хранятся по сессии, если он входит в аккаунт — корзина плавно синхронизируется.

**Трудность 2: Сложные характеристики товаров.**
Компьютер — сложный товар. У него есть процессор, видеокарта, память. Хранить это в одном текстовом поле было бы непрофессионально.
* **Решение:** Я спроектировал реляционную структуру из трех таблиц (`Product`, `SpecGroup`, `ProductSpec`). А чтобы это было удобно заполнять, я использовал функционал *Django Admin Inlines*, который позволяет добавлять бесконечное количество характеристик прямо на странице редактирования товара.

**Трудность 3: Синхронизация остатков.**
* **Решение:** Написал логику, которая при оформлении заказа автоматически вычитает купленное количество товара со склада, а если товар заканчивается — система автоматически ставит ему статус «Нет в наличии».

## 5. Слайд: Выводы и планы по развитию
**Выводы:**
Разработанный проект полностью выполняет поставленные цели и является готовым MVP (минимально жизнеспособным продуктом). Архитектура базы данных продумана так, что проект можно бесконечно масштабировать, добавляя тысячи товаров, а использование Django делает сайт защищенным от большинства веб-уязвимостей (CSRF, SQL-инъекции, XSS).

**Планы по развитию проекта (Roadmap):**
1. **Интеграция онлайн-оплаты:** Подключение банковских API (например, ЮKassa или Stripe) для приема платежей картой прямо на сайте.
2. **Email-уведомления:** Настройка реального SMTP-сервера для автоматической отправки чеков на почту и восстановления забытого пароля.
3. **Система отзывов:** Добавление возможности оставлять отзывы и ставить рейтинг товарам для повышения доверия покупателей.
